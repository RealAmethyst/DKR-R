# DKR-R v1.0.9 Release Build

Extract the entire Windows folder and open DKR-R.exe. Keep assets and libexec
with it. Linux/Steam Deck: make the AppImage executable and launch it. Android:
install over the existing compatible signed app; back up saves before updating.

Bring your own supported US v1.0 or US Rev A/v1.1 ROM. No ROM is included.
Normal mods use one personal Adventure. Online and development progress stay
separate. Older mod-set saves remain available in Backups & Recovery.

DKR-R Online adds Public/Friends browsing, shared Discord sign-in, connected
account counts and Private/Public hosting. Public discovery uses the deployed
website API; the existing peer/Rollback path runs the game. Spectators,
connection Scoreboard, custom cars, achievements and texture tools are included.
Running-spectator entry has a separate service gate. No new Apple package is
part of this build set; earlier Apple releases retain their own versions.

Read RELEASE-NOTES.txt for the changes. Guides and support:
https://github.com/ThatGuyMcd/DKR-R
https://discord.com/invite/AMWfXdBjNP

Automatic updates need newly signed DKR-R-update.json/DKR-R-update.sig assets.
Do not reuse an old signature or alter package bytes after signing. Keep all peers on the
same compatible release for Online. SDK 2/Bible/examples are separate downloads.
No offline Player Guide is included. Keep all required licence notices.
